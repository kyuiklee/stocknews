종목 추가

추가·삭제·이동한 뒤 변경 저장을 누르면 GitHub 저장소의 목록이 바뀌고, 2~3분 뒤 새 종목의 뉴스가 바로 수집됩니다.

GitHub 연결

목록을 앱에서 바로 저장하려면 이 저장소에만 쓸 수 있는 GitHub 토큰이 한 번 필요합니다. 토큰은 이 폰의 브라우저에만 저장됩니다.

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → 이 저장소
  3. Permissions → Repository permissions → Contents: Read and write
  4. 만료일은 원하는 대로 (예: 1년) 정하고 생성된 토큰을 아래에 붙여넣기
