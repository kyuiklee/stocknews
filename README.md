# 종목 뉴스

보유 종목과 관심 종목의 뉴스·공시, 시장 전체의 자사주 공시, 가치투자·행동주의 운용사의 5% 지분 공시를 하루 4번 자동으로 모아서 폰 앱 화면에 보여 줍니다.

탭: **보유 · 관심 · 자사주 · 투자자문 · 종목**

- **앱 주소:** https://kyuiklee.github.io/stocknews/
- 폰에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 자동 수집 시각 (매일)
| 시각 (KST) | 실제 시작 |
|---|---|
| 06시 | 05:50 |
| 12시 | 11:50 |
| 18시 | 17:50 |
| 24시 | 23:50 |

시세는 이와 별도로 **국내 장중(09:20~15:20) 매시, 미국 장중(23:40~05:40) 매시** 자동으로 다시 받고, 앱 **종목 → 자산**의 **지금 시세 받기** 버튼으로 원할 때 받을 수 있습니다(약 1분, 토큰에 Actions 권한 필요).

GitHub 예약 실행은 수 분~수십 분 늦게 시작될 수 있습니다. 급할 때는 GitHub 앱 → `stocknews` → Actions → **종목 뉴스 수집** → Run workflow 로 바로 실행할 수 있습니다.
앱에서 종목을 추가·삭제해 저장하면 그때도 바로 한 번 수집합니다.

## 수집원
| 구분 | 국내 종목 | 미국 종목 |
|---|---|---|
| 뉴스 | 네이버 증권 종목 뉴스(종목코드 기준), 구글 뉴스(국문) | 구글 뉴스(영문·국문), 야후 파이낸스 |
| 공시 | DART (`DART_API_KEY` 비밀값 필요) | SEC EDGAR (8-K, 10-Q, 10-K 등) |

- 제목이 거의 같은 기사는 하나로 묶고 매체 수를 보여 줍니다.
- 제목에 실적·계약·임상·자금조달·주주환원·M&A·증권가 의견·리스크 낱말이 있으면 태그를 붙이고 **중요** 거르기에 나옵니다.
- 최근 7일, 종목당 80건까지 보관합니다.

## 자사주 탭
- DART 주요사항보고서의 자기주식 취득·취득신탁계약·신탁해지·처분 결정, 거래소 공시의 주식소각 결정 (코스피·코스닥·코넥스 전체)
- 상세 API로 예정 금액·기간·목적·방법(신탁 기관)을 붙이고 시가총액 대비 비율을 계산
- 처음 실행 때 최근 90일(소각은 30일)을 받고, 120일 보관

## 투자자문 탭
- 주식등의대량보유상황보고서(5% 이상 보유 보고) 중 `advisors.json` 의 운용사가 낸 것
- 보유비율·증감·보고사유를 붙이고 신규 / 늘림 / 줄임 / 5% 미만으로 구분
- **운용사별 보유**: 운용사·회사별 마지막 보고 기준 5% 이상 종목
- **운용사 목록**: 앱에서 추가·삭제 (최근 지분 공시를 낸 다른 운용사도 추천)
- 처음 실행 때와 운용사를 추가했을 때 1년치를 받고, 2년 보관

## 종목 탭 (내 자산)
- **자산**: 총 평가액·원금·손익, 종목별/산업군별/국내·해외 비중(원형 그래프), 보유 종목별 수익률·PER·PBR·배당·ROE·해자, 현금·기타 자산
- **수익률**: 평가액과 원금 그래프, 코스피·코스닥 벤치마크 비교(누적 수익률 그래프·기간별 표), 일·월·연 수익률(입출금을 뺀 시간가중 수익률)과 손익
- **기록**: 매수·매도·입금·출금·배당·이자·기타 자산(현금·예금·적금·CMA·펀드·연금) 입력, 파일 백업·가져오기
- 종목·ETF는 이름이나 코드로 검색 (`site/data/symbols.json`: 국내 주식·ETF 전체, 미국 티커 — 하루 한 번 갱신)
- 자산의 보유 종목마다 **추가 매수 / 매도 / 수량 맞추기**, 맨 위 **+ 종목 추가**로 수량·평단가만 넣어 시작
- 매매·금액 기록은 **폰 브라우저에만** 저장되고 서버에는 올라가지 않습니다. 서버는 공개 정보만 만듭니다:
  - `site/data/prices.json` 보유·관심·시세추적 종목의 약 5년치 종가와 원/달러 환율
  - `site/data/market.json` PER·PBR·배당수익률·ROE·업종·시가총액 (국내 네이버 증권, 미국 야후 파이낸스)
  - `site/moat.json` 산업군과 해자 평가 (Claude 작성, 직접 고쳐도 됨)
- **보유 뉴스 목록은 자산 기록 기준으로 자동으로 맞춰집니다**: 매수 기록이 있는 종목 = `stocks.json` 의 `portfolio` (종목 이름·코드만 올라감). 다 판 종목은 관심으로 옮기거나 지움(처음 맞출 때 선택). ETF처럼 '시세만 추적'으로 넣은 종목은 `prices` 에 들어가고 뉴스는 모으지 않음
- **관심 목록**: 관심 종목만 앱에서 추가·삭제

## 종목 바꾸기
1. 보유 종목: **종목 → 기록**에서 매수·매도 기록 (자동 반영)
2. 관심 종목: **종목 → 관심 목록**에서 추가·삭제 후 **변경 저장**
3. 둘 다 처음 한 번 GitHub 토큰 연결 필요 (앱 안에 방법 안내). GitHub에서 `stocks.json` 을 직접 고쳐도 됩니다

`stocks.json` 고급 항목 (선택):
- `alias`: 국내 종목의 다른 이름 (예: NAVER → `["네이버"]`)
- `en`, `alias_en`: 미국 종목 영문명과 다른 이름 (제목 거르기에 사용)
- `q_ko`, `q_en`: 구글 뉴스 검색어를 직접 지정 (이름이 흔한 낱말일 때)

## 구성
- `stocks.json` — 보유·관심 종목 목록
- `advisors.json` — 지분 공시를 추적할 운용·자문사 목록
- `engine/config.json` — 보관 기간, 수집원 켜고 끄기, 묶음 기준 등
- `engine/collect.py` — 뉴스 수집·묶기·태그
- `engine/disclosures.py` — 자사주·운용사 지분 공시 (DART)
- `engine/market.py` — 시세·환율·재무 지표
- `engine/prices_only.py` + `.github/workflows/prices.yml` — 시세만 빠르게 갱신 (뉴스·공시는 그대로 둠)
- `site/pf.js` — 내 자산 화면과 수익률 계산 (폰에서 실행)
- `site/` — 앱 화면

뉴스 모음이며 매수 권유가 아닙니다.
