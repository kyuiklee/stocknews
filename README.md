# 종목 뉴스

보유 종목과 관심 종목의 뉴스·공시를 하루 4번 자동으로 모아서 폰 앱 화면에 보여 줍니다.

- **앱 주소:** https://kyuiklee.github.io/stocknews/
- 폰에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

## 자동 수집 시각 (매일)
| 시각 (KST) | 실제 시작 |
|---|---|
| 06시 | 05:50 |
| 12시 | 11:50 |
| 18시 | 17:50 |
| 24시 | 23:50 |

GitHub 예약 실행은 수 분~수십 분 늦게 시작될 수 있습니다. 급할 때는 GitHub 앱 → `stocknews` → Actions → **종목 뉴스 수집** → Run workflow 로 바로 실행할 수 있습니다.
앱에서 종목을 추가·삭제해 저장하면 그때도 바로 한 번 수집합니다.

## 수집원
| 구분 | 국내 종목 | 미국 종목 |
|---|---|---|
| 뉴스 | 네이버 증권 종목 뉴스(종목코드 기준), 구글 뉴스(국문) | 구글 뉴스(영문·국문), 야후 파이낸스 |
| 공시 | DART (`DART_API_KEY` 비밀값 필요) | SEC EDGAR (8-K, 10-Q, 10-K 등) |

- 제목이 거의 같은 기사는 하나로 묶고 매체 수를 보여 줍니다.
- 제목에 실적·계약·임상·자금조달·주주환원·M&A·증권가 의견·리스크 낱말이 있으면 태그를 붙이고 **중요** 거르기에 나옵니다.
- 최근 7일, 종목당 80건까지 보관합니다.

## 종목 바꾸기
1. 앱의 **종목** 탭에서 추가·삭제·이동 후 **변경 저장** (처음 한 번 GitHub 토큰 연결 필요 — 앱 안에 방법 안내)
2. 또는 GitHub에서 `stocks.json` 을 직접 수정

`stocks.json` 고급 항목 (선택):
- `alias`: 국내 종목의 다른 이름 (예: NAVER → `["네이버"]`)
- `en`, `alias_en`: 미국 종목 영문명과 다른 이름 (제목 거르기에 사용)
- `q_ko`, `q_en`: 구글 뉴스 검색어를 직접 지정 (이름이 흔한 낱말일 때)

## 구성
- `stocks.json` — 보유·관심 종목 목록
- `engine/config.json` — 보관 기간, 수집원 켜고 끄기, 묶음 기준 등
- `engine/collect.py` — 수집·묶기·태그
- `site/` — 앱 화면

뉴스 모음이며 매수 권유가 아닙니다.
